# Espace Parents CE2 — V35.55

Patch « La semaine en un coup d’œil » — badges thématiques.

- Suppression du compteur générique **✏️ 1 devoir / 2 devoirs / 3 devoirs**.
- Affichage de **badges explicites** selon les devoirs du jour : **📖 Lecture**, **📝 Dictée**, **➕ Maths**, **🧠 Vocabulaire**, **✍️ Écriture**, **🇬🇧 Anglais**, **📚 Leçon**.
- Les badges sont **déduits automatiquement** du contenu réel des devoirs du jour.
- Les doublons sont évités : par exemple, **Orthographe — Je prépare ma dictée** et **Je prépare ma dictée** n’affichent qu’un seul badge **📝 Dictée**.
- La pastille verte **🏃 Sport** est conservée, **une seule fois**.
- Les évaluations restent signalées par leur pastille dédiée.
- Jours sans classe, week-ends, jours fériés et vacances gardent leur indication explicite.

Fichiers modifiés : `index.html`, `parents.js`.
