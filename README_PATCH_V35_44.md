# PATCH V35.44 — Espace Parents

Patch simple, sans PowerShell.

## Installation
Remplacer uniquement le fichier `index.html` situé à la racine du dépôt :

`espace-parents-ce2/index.html`

## Modification
Dans **Infos de la classe → Rappels du cahier de liaison** :

- carte bleue **INFO** : 17h05–17h15, point d’information sur la coopérative scolaire avec le Directeur, sous le préau des CE2 ;
- carte orange **IMPORTANT** : 17h15–18h15, réunion de rentrée avec l’enseignant, dans la classe de votre enfant ;
- rappel visuel des horaires ;
- le bloc disparaît automatiquement après le lundi 7 septembre à 18h16.
